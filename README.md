OpenXTalk xBuilder Extension AVMIDIPlayer
This extension wraps Apple's AVMIDIPlayer API to enable play back of MIDI file data using SoundBank files (.DLS or .SF2) for the instrument sounds.
By default the library will look on the system, for the CoreAudio included Roland GM .DLS soundbank.
Stacks can use it to play MIDI music sequences as background music in a way that doesn't effect script execution performance.
